# Раздача сборок через GitHub

Создать репозиторий за вас я не смог — у интеграции нет прав на создание.
Ниже команды, это минута.

## Почему это стоит сделать

У GitHub Releases **2 ГБ на файл, ноль ограничений по трафику**, и релизы
не входят в квоту хранилища. То есть 173 МБ раздаются оттуда бесплатно и
сколько угодно раз, а на darave.ru остаётся кнопка со ссылкой. Вопрос
места и лимитов хостинга снимается целиком.

Одна оговорка: релизы приватного репозитория видны только тем, у кого есть
доступ к коду. Поэтому — **отдельный публичный репозиторий только под
сборки**, без исходников. Исходники остаются приватными там, где они
сейчас.

## Создать

```powershell
gh auth login                      # один раз
gh repo create kam1k88/darave-releases --public `
  --description "DARAVE — сборки для Windows"
```

## Выложить сборку

```powershell
cd C:\Users\kam1k88\DARAVE
gh release create v1.0.0 `
  installer\DARAVE-1.0.0-setup.exe `
  --repo kam1k88/darave-releases `
  --title "DARAVE 1.0.0" `
  --notes-file RELEASE_NOTES.md
```

Ссылка для сайта получится постоянная:

```
https://github.com/kam1k88/darave-releases/releases/latest/download/DARAVE-1.0.0-setup.exe
```

`latest` удобен тем, что не надо править сайт при каждой версии — но имя
файла в нём версионное, так что при выпуске 1.1.0 ссылку всё же поправить
придётся. Чтобы не править никогда, называйте файл в релизе без версии:
`DARAVE-setup.exe`, а версию держите в теге.

## Про .msi

Вы написали «.msi», а собирается у нас `.exe` (Inno Setup). Это разные
вещи, и разница не косметическая.

`.msi` нужен, когда программу разворачивают централизованно — через
групповые политики в организации. Для этого его и придумали.

Для человека, который скачивает установщик себе на компьютер, `.exe`
привычнее и надёжнее: Inno Setup спокойно кладёт 450 МБ, ставит без прав
администратора и даёт нормальный мастер. Собрать `.msi` можно (WiX
Toolset), но это заметно более капризный инструмент, и на полугигабайтной
полезной нагрузке он капризничает особенно.

Так что: если у вас нет на примете организации, которая будет ставить
DARAVE по политике на двадцать машин, — `.exe` правильнее. Скажите, если
такая задача есть, тогда сделаю `.msi` через WiX.

## Сборка на стороне GitHub (позже)

Actions умеет собирать установщик по тегу и сам класть его в релиз. Для
публичных репозиториев минуты бесплатны, для приватных — 2000 в месяц, и
windows-раннер тратит их вдвое быстрее: при вашей десятиминутной сборке
это около сотни сборок в месяц.

Сейчас это не срочно. Пока сборка запускается одной командой у вас на
машине, выигрыш небольшой, а возни с секретами (сборку надо будет
подписывать и класть в чужой репозиторий) — много.
