# Тестовый платёж, пока идёт проверка договора

Всё ниже — с **тестовым** магазином ЮKassa. Деньги не списываются,
карта не нужна настоящая.

## Главное, что стоит знать заранее

**СБП в тестовом магазине не работает.** У нас он стоит по умолчанию,
поэтому в тестовом режиме код принудительно переключается на карту — иначе
первый же прогон упирался бы в невнятный отказ, и было бы не понять, дело
в ключах, в коде или в чём-то ещё. Переключение сделано в `buy.php`,
трогать не надо.

Значит СБП вы проверите только после одобрения договора, на боевых
ключах и на настоящие деньги. Сделайте это на «Личной» — 3 900 ₽ себе же,
с возвратом через кабинет ЮKassa.

## 1. Разложить файлы

```
/www/darave.ru/
├── index.html  offer.html  requisites.html  .htaccess
├── download/DARAVE-setup.exe
├── app/index.html
└── api/   ← .htaccess, _config.php и все .php
```

Сейчас `api/` на сайте нет: `https://darave.ru/api/me.php` отдаёт 404.
Пока его нет, ни вход, ни оплата работать не могут.

## 2. База

phpMyAdmin → база `u3647882_darave.bd` → вкладка SQL → выполнить `db.sql`.
Должно появиться шесть таблиц.

## 3. `_config.php`

Скопировать из `_config.sample.php` и заполнить:

```php
'db' => [ ..., 'pass' => 'пароль базы' ],
'yookassa' => [
    'shop_id'    => 'идентификатор ТЕСТОВОГО магазина',
    'secret_key' => 'ключ ТЕСТОВОГО магазина',
    'test_mode'  => true,          // ← на время проверки
],
'selftest_secret' => 'длинная-случайная-строка',
```

Тестовый магазин заводится в кабинете ЮKassa отдельной кнопкой, и
**ключи у него свои** — боевые сюда не подставлять.

## 4. Проверить установку

```
https://darave.ru/api/selftest.php?secret=длинная-случайная-строка
```

Одна страница, где по очереди проверяется: версия PHP и расширения,
https, база и таблицы, ключи ЮKassa (настоящим запросом к их API),
отвечает ли адрес уведомлений, открываются ли страницы, которые ЮKassa
смотрит вручную. Красное чините сверху вниз.

Без секрета страница отдаёт 404 — она показывает версию PHP, имя базы и
состояние ключей, и отдавать это кому попало незачем. Перед запуском её
можно удалить совсем.

## 5. Адрес уведомлений

Кабинет ЮKassa → Интеграция → HTTP-уведомления:

```
https://darave.ru/api/yookassa_webhook.php
```

События: `payment.succeeded` и `payment.canceled`. У тестового магазина
адрес уведомлений задаётся отдельно от боевого.

## 6. Собственно тест

1. Откройте `https://darave.ru/app/`, зарегистрируйтесь.
2. Нажмите «Купить «Личную»» — или зайдите сразу на `/app/?buy=personal`.
3. На странице ЮKassa введите тестовую карту **без 3-D Secure**:

   | Карта | Номер |
   |---|---|
   | Visa | `4111 1111 1111 1111` |
   | Mastercard | `5555 5555 5555 4444` |
   | Мир | `2202 4743 0132 2987` |

   Срок — любой будущий, CVC — любые три цифры.

4. Вас вернёт на `/app/?paid=<номер>`. Страница опрашивает статус до
   минуты и показывает «Оплачено».

Чтобы проверить отказ, возьмите карту с истёкшим сроком:
`5555 5555 5555 4543`. Должно появиться «Платёж отменён» и предложение
попробовать снова — а не «что-то пошло не так».

## 7. Что смотреть, если не сошлось

```sql
SELECT id, user_id, tier, amount, status, payment_id, paid_at
  FROM orders ORDER BY id DESC LIMIT 5;

SELECT email, tier, tier_until FROM users ORDER BY id DESC LIMIT 5;
```

| Что видно | Где искать |
|---|---|
| заказа нет вовсе | `buy.php` не отработал — смотрите `selftest.php` и логи сайта |
| заказ `pending`, а деньги «прошли» | уведомление не дошло: адрес в кабинете ЮKassa, ответ webhook не 200 |
| заказ `succeeded`, тариф не изменился | ошибка транзакции в `yookassa_webhook.php` — в логе сайта |

Логи PHP: ispmanager → **Журналы сайтов** → `darave.ru`.

## 8. Перед боевым запуском

1. `'test_mode' => false` и боевые ключи.
2. Адрес уведомлений — тот же, но в настройках **боевого** магазина.
3. Купить себе «Личную» по СБП и вернуть через кабинет. Это
   единственный способ убедиться, что СБП работает: в тесте его нет.
4. Выдать чек в «Мой налог» и поставить `receipt_sent = 1` у заказа.
5. Удалить `api/selftest.php`.
