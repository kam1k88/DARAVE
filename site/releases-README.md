# DARAVE — сборки для Windows

Помощник для сборки диджейского сета: разбирает вашу библиотеку,
предлагает переход — пару треков, приём и две точки в секциях, — даёт
послушать и решить. Одобренное складывается в сет и сводится в файл.

Сайт: **[darave.ru](https://darave.ru)**

Здесь только установщики. Исходников в этом репозитории нет.

## Скачать

Последняя версия — на вкладке [Releases](../../releases/latest).

## Что нужно

| | |
|---|---|
| Система | Windows 10 и 11, 64 бита |
| Место на диске | около 450 МБ (пакет слоёв — ещё 3 ГБ, скачивается отдельно по кнопке) |
| Память | 8 ГБ; для разделения на слои 16 ГБ |
| Видеокарта | необязательна; с NVIDIA слои считаются в разы быстрее |

Ни Python, ни Mixxx, ни прав администратора не требуется.

## Windows покажет предупреждение

При запуске установщика появится «Windows защитила ваш компьютер». Так
система встречает любую программу без платной подписи разработчика — это
не про вирус и не про повреждённый файл.

Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.

Подпись будет. Пока её нет, честнее предупредить, чем делать вид, что
всё гладко.

## Проверить, что файл скачался целиком

У каждого релиза на его странице указана контрольная сумма SHA-256.
Сверить у себя:

```powershell
Get-FileHash .\DARAVE-setup.exe
```

Не совпало — файл побился при скачивании, качайте заново.

## Музыка остаётся у вас

Разбор и сведение идут на вашем компьютере. Загружать фонотеку никуда не
нужно, и она никуда не уходит. Интернет нужен, чтобы войти в учётную
запись и чтобы дописать стили треков из открытых каталогов.
